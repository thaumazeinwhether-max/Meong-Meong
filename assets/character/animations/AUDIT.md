# クルムのフレーム監査

セル番号は上から行、左から列（ともに1始まり）。元PNGは保存し、採用範囲と表示基準のみ変更する。

## 原因

- 正面と横向き、座位と伏臥位、歩行と跳躍を同じ短いループに混在させていた。
- 362px等分セルと実際のイラスト配置が一致しない。特にaction 1行目の足先は次行にはみ出す。
- 透明余白込みの中央配置なので、motionの非透明領域の下端は241～347px程度まで変化する。
- 左向き素材とゲームの進行方向がコードで区別されていない。正面も一律に反転して尾の位置が変わる。
- ワンショットが無条件で中断され、次状態への遷移時に余り時間が捨てられる。

## 限定的な追加素材

全素材の作り直しは行わず、次の2シートだけを内蔵ImageGenで追加した。正式マスターをidentity referenceとして渡した。既存PNGと正式マスターは上書きしていない。

- `kurum_gait_v2.png`：1254×1254、2×2、左向き4位相。頭部・胴体を保ち脚の運びだけを変える。walk/run/chase_ballで共有。元の歩行3姿勢の不連続な並びを置換。
- `kurum_rest_v2.png`：1254×1254、2×2、正面の座位／肘を下げる／伏せる／閉眼して休む。座位は既存待機の方がつながるため新規座位フレームは実行時に使わない。残り3枚を伏せ・休憩・起床に採用。

### 生成プロンプトセット（設計指示）

共通：添付の正式マスターを唯一のidentity referenceとする。同じ白いマルチーズ、平たい頭頂、太く長い白い眉毛状の毛、点状の目、小さな黒い鼻、丸い体型、同じ線・塗り・配色を維持。透明PNG、文字・背景・影・装飾なし。各セルのスケールと位置を一致させ、毛先を切らない十分な透明余白を確保する。

歩行：小さな2×2のゲーム用スプライトシート。すべて左向きの横顔、同一カメラ。近側前脚が前→すれ違い→反対側前脚が前→すれ違いの4位相。頭と胴体の形状・寸法を同一に保ち、脚と尾のみを変える。跳躍や大きなポーズ変更は禁止。

休憩：小さな2×2のゲーム用スプライトシート。正面の同じクルムが、座る→前脚の肘を下げる→伏せる→伏せたまま目を閉じる。顔・頭幅・眉毛の同一性を維持し、寝るために別の顔や大きな体型変化を加えない。

### 生成後の選別・補正

両シートを正式マスターと再比較した。眉毛・鼻・配色・線の特徴を確認したうえで、正面の新規座位を連結から除外。生成結果の透明余白や足元は完全には統一されていないので、`src/sprite_layout.py`で各フレームの切出し・頭幅・足元を実測指定して補正する。頭幅による一様拡縮であり、縦横比を変える変形はしない。足の位置ではなく空中の胴体位置を維持すべき姿勢には仮想支持点を設定する。

`CharacterAnimator.draw()`へ渡す座標は共通の支持点。画面側で画像左上や透明セルの下端を独自に合わせない。正面は左右反転せず、横顔だけ元の向きと移動方向から反転する。ジャンプの進行方向は常に右。

## 再生と状態遷移

- まばたき80ms/枚、尾振り180ms/枚、喜び200ms/枚。
- 歩行・走行は経過時間から計算した実移動距離に同期。歩行1周期は表示サイズ×0.26、走行は×1.05。移動ゼロでは脚も進めない。
- 伏せ300ms/枚、起床320ms/枚、着地90ms/枚。上昇・頂点・下降は鉛直速度から選ぶ。
- 部屋は待機4.5～8秒が基本。歩行→停止→待機、座位→立つ→待機、伏せ→休息7～12秒→起床→待機。ランダム選択は待機だけで行う。
- ワンショットは終了通知後に遷移し、残り時間を引き継ぐ。新しい要求は待ち行列1件で保留。ジャンプ入力等の操作応答を優先する場合のみ明示的に中断する。
- タイトル・吠え・解放画面の全身の上下跳ねを除去。キャッチでは専用225msの短い反応を使い、長い食事動作に切り替えない。

## 再確認方法

`.venv\Scripts\python.exe -m tools.preview_animation` で補正後のフレーム比較画像と部屋・ジャンプ画面を `data/animation_review/` に出力する（Git対象外）。セーブデータは変更せず、部屋7,200フレーム・ジャンプ1,800フレームを連続描画する。

機械テストは時間・向き・支持点・状態・画像の欠けを検証できるが、「同じ個体に見えるか」「滑りが感じられないか」の最終判断は実機の連続再生で行う。ゲームの固定値、物理定数、難易度、SQLite仕様は今回変更していない。
